# Press kit — DJ Savic

Página de apresentação do DJ e produtor Savic, com conteúdo de mídia, vídeos, links para plataformas musicais e formas de contato.

**Demonstração informada no repositório:** [GitHub Pages](https://rafael-m-silva.github.io/PRESSKIT-DJ-SAVIC/)

## Sobre o projeto

O site reúne a identidade visual do artista em uma página estática. A navegação oferece acesso a materiais de divulgação, redes e contato. A seção de mídia usa imagens e vídeos que já estão em <code>assets/</code>.

## Conteúdo e interações

- Apresentação visual e mídia kit do artista.
- Vídeos e imagens incorporados ao site.
- Links para YouTube, SoundCloud, Instagram, Drive e WhatsApp.
- Animações de entrada com ScrollReveal.

## Tecnologias e estrutura

HTML, CSS e JavaScript, com a biblioteca ScrollReveal carregada por CDN. Não há build, backend nem banco de dados.

~~~text
index.html          página principal
assets/css/         estilos
assets/js/script.js animações de entrada
assets/img/         imagens e identidade visual
assets/video/       vídeos da página
assets/icon/        ícones
~~~

## Como executar

~~~bash
git clone https://github.com/Rafael-M-Silva/PRESSKIT-DJ-SAVIC.git
cd PRESSKIT-DJ-SAVIC
~~~

Abra <code>index.html</code> no navegador ou sirva a pasta em um servidor estático. Fontes, ScrollReveal e links externos exigem conexão com a internet.

## Revisão pendente

Os metadados Open Graph e Twitter em <code>index.html</code> ainda usam o domínio de exemplo <code>www.seusite.com</code>. Antes de divulgar a página, substitua esses endereços pelo domínio e imagem reais. O código não foi alterado nesta revisão documental.
